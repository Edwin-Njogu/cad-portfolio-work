# Geneva Mechanism

A FreeCAD mechanical design project representing a Geneva mechanism assembly.

## Included

- Complete assembly
- Driver
- Geneva disc
- Axles
- Base
- Pin
- Roller
- Lever

The individual FreeCAD files are kept together in the models directory so the project is easier to inspect and reuse.

## Skills Demonstrated

- Part modeling
- Mechanical mechanism assembly
- Component organization
- FreeCAD CAD workflow
