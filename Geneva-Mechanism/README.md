# Geneva Mechanism

A mechanical CAD project developed in FreeCAD to model and assemble a Geneva mechanism. The project demonstrates individual component modeling, mechanism assembly, component organization, and structured CAD delivery.

## Project Overview

The Geneva mechanism is represented as a complete assembly built from separate mechanical components. The repository includes both the assembly file and the individual component files so the design can be inspected at part and assembly level.

## My Work

- Modeled the individual mechanism components
- Developed the complete Geneva mechanism assembly
- Positioned and integrated the components within the assembly
- Organized the individual part files and assembly file into a structured project
- Prepared the CAD files for portfolio review and reuse

## Source Files

The `models/` directory contains the editable FreeCAD `.FCStd` files for the individual components and complete assembly.

The files are intentionally kept as separate source models so another CAD user can inspect the component-level work as well as the assembled mechanism.

## Project Context

This project forms part of my mechanical engineering CAD portfolio and demonstrates a complete workflow from individual mechanical component modeling to assembly-level integration.
